# Points reliés : logiciels et actions à relire

À chaque partie, les 9 logiciels sont tous affichés et 10 actions sont tirées au hasard dans la liste ci-dessous (26 actions). Un logiciel peut recevoir plusieurs actions ; certains peuvent n'en recevoir aucune dans une partie.

Si vous n'êtes pas d'accord avec une ligne, signalez-la via les bugs.
